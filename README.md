# Starlight Reverie · 夢光幻境

A pastel-fantasy 2D side-scrolling action platformer across 5 whimsical realms — playable directly in your browser.

## Play Online · 線上遊玩
- **Play Now (with Global Leaderboard · 含線上全球排行榜):** https://skyhuang1208.github.io/starlight-reverie/
- **Play Offline:** Clone/download this repo and open `index.html` in any modern browser.

## ✨ 金手指區 (Golden Finger Cheats)

Available on the Starter Menu for relaxed play or boss practice:
- **無敵不扣血 (`No Damage`)** — Play without taking damage
- **一拳必殺 (`1-Punch KO`)** — Defeat enemies and bosses in a single hit

> Runs with cheats enabled are marked **Unranked** and excluded from the leaderboard.

## Controls · 操作方式

Both control styles work seamlessly at the same time:
- **WASD + Mouse:** `A / D` Move · `W / Space` Jump · `S / Shift` Slide / Drop · **Mouse** Aim · `LMB` Attack · `RMB` Skill · `Q` Ult
- **Keyboard Only:** `← / →` Move · `↑ / ↓` Vertical Aim · `Space` Jump · `Shift / ↓` Slide / Drop · `1` Attack · `2` Skill · `3` Ult
- **System:** `Esc` / `P` Pause · `M` Mute
