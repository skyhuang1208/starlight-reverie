# Starlight Reverie · 夢光幻境

A pure HTML5 Canvas + Web Audio API 5-stage pastel-fantasy 2D action platformer playable directly in the browser — zero installs, zero build step!

## Play Online
- **GitHub Pages:** `https://skyhuang1208.github.io/starlight-reverie/` *(available once GitHub Pages is enabled)*

## Playable Heroes
- **Luna · 法師 (Beginner):** Fires 3 homing Elemental Bolts (Fire, Ice, Lightning) with splash damage & floaty jumps.
- **Pip · 射手 (Intermediate):** Fires 5 metallic silver bullets in a ±45° spread (hold **W / ↑** to shoot straight up!).
- **Lyra · 戰士 (Advanced):** Sweeping greatsword deflects enemy projectiles, launches white-blue 劍氣 waves & Celestial Flying Swords, plus 2-jump Air-Slice dive.

## Dual Non-Colliding Controls
- **Style A:** `WASD` + `Space` + `Shift` (Slide) + `LMB` (Attack) + `RMB` (Skill) + `Q` (Ultimate)
- **Style B:** `Arrow Keys` + `Space` + `Shift` (Slide) + `1` (Attack) + `2` (Skill) + `3` (Ultimate)
- **Pause / Mute:** `Esc` or `P` to Pause · `M` to Toggle Audio
