✦ HOW TO PLAY · 操作說明 ✦

Welcome to Starlight Reverie

Choose whichever control style feels most comfortable—both work at the same time!

🖱️ Style A · WASD + Mouse (360° Aim)

  • A / D — Move Left / Right
  • W / Space — Jump & Double Jump
  • S / Shift — Slide / Drop Bar
  • Mouse Pointer — Aim 360° Direction!
  • LMB / RMB / Q — Attack / Skill / Ult

⌨️ Style B · Arrows + 1 / 2 / 3 (0° / 90° Aim)

  • ← / → — Move & Aim Left / Right (0°)
  • ↑ / ↓ (air) — Hold to Aim Straight Up / Down (90°)
  • Space — Jump & Double Jump
  • Shift / ↓ — Slide / Drop Bar
  • 1 / 2 / 3 — Attack / Skill / Ult
🔥 Luna: Fire Attack · ❄️ Ice Skill · ⚡ Lightning Ult! 🌟 Pip: 30° Silver Burst + Piercing Golden Skill & Ult! 🗡️ Lyra: Blade Surge cuts & blocks frontal shots, then fires 劍氣!
